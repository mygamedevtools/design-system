## Profile name

## Introduction headline

Open-source tools for Unity

## Introduction paragraph

My Gamedev Tools makes open-source packages for Unity. Use My Scene Manager to load, unload, and transition scenes from C#, with support for custom loading screens and Addressables.

## About

My Gamedev Tools is an independent open-source project maintained by @thatjoaoguy. Visit our GitHub to browse the source code, report an issue, or contribute.

## Source artwork

Run `npm run dev` from the repo root. Render [the icon template](../../templates/asset-store/icon.html) with `?publisher` for the profile picture and [the publisher banner template](../../templates/asset-store/publisher-banner.html) for the promo image. Both use the shared brand tokens and logo SVGs. Capture `<body>` at 1× to match the export dimensions.
