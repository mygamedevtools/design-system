# @mygamedevtools/docusaurus-theme

Applies the My Gamedev Tools brand to a Docusaurus 3 site: Russo One / Rethink Sans / Red Hat Mono
(self-hosted through Fontsource), Cartridge colors in light and dark, the tri-color navbar rule, and
the logo files.

## Install

The theme isn't on npm. Each design-system release has the tarball attached; install it by URL:

```sh
npm i https://github.com/mygamedevtools/design-system/releases/download/v1.0.0/mygamedevtools-docusaurus-theme-1.0.0.tgz
```

To update, install the newer release's URL.

## Setup

```js
// docusaurus.config.js
import mgtTheme from '@mygamedevtools/docusaurus-theme';

export default {
  favicon: 'img/mgt/favicon.svg',
  staticDirectories: ['static', mgtTheme.staticDir],
  plugins: ['@mygamedevtools/docusaurus-theme'],
  themeConfig: {
    colorMode: { respectPrefersColorScheme: true },
    navbar: {
      logo: {
        alt: 'My Gamedev Tools',
        src: 'img/mgt/mark-light.svg',
        srcDark: 'img/mgt/mark-dark.svg',
      },
    },
  },
};
```

Remove any `--ifm-color-primary*` overrides from the site's `custom.css`, since the theme sets them.

## Files under `/img/mgt/`

| File | Use |
| --- | --- |
| `favicon.svg` | Favicon; follows the OS color scheme |
| `mark-light.svg`, `mark-dark.svg` | Navbar logo for light and dark mode |
| `lockup-horizontal-{light,dark}.svg` | Mark plus wordmark, one line |
| `lockup-stacked-{light,dark}.svg` | Mark plus wordmark, two lines |
| `mark-{light,dark}-{128,256,512}.png` | Raster fallbacks, e.g. `og:image` compositions |

`src/tokens.css` and `static/` are generated by `npm run build` at the repo root, which runs
automatically when the tarball is packed.
